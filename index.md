DevDocs is a lightweight developer documentation platform for shipping clear,
searchable technical content — API references, how-to guides, and architecture
notes — as a fast static website.

Built with **Jekyll**, Markdown, and semantic HTML, DevDocs keeps your docs
close to the code: versionable, reviewable, and deployable anywhere static
files can live. Use the collection-based guides, sidebar navigation, and
client-side search to publish documentation that stays maintainable as your
product grows.
