Capabilities

Built for documentation teams

A focused set of primitives — not a CMS, not a theme marketplace.

  • Collection-based docs

    Organize guides in _docs/ with ordered navigation, permalinks, and previous/next paging.

  • Readable by design

    Typography, spacing, and a restrained brand purple keep long-form technical writing comfortable.

  • Search that ships

    Liquid generates a JSON index at build time. Vanilla JavaScript filters it in the browser.

  • CI-ready publish

    GitHub Actions builds with production baseurl and deploys to GitHub Pages from main.
